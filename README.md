# Ivan – Front-End Portfolio

Osobna portfolio stranica napravljena u sklopu Codecademy **Front-End Engineer** puta.

## Opis
Statična stranica s dvije podstranice:
- **Projekti** (`index.html`) – odabrani projekti sa slikom, sažetkom i tehnologijama
- **Kontakt** (`contact.html`) – kontakt podaci i forma s validacijom

## Značajke
- 🌙 Tamna / svijetla tema (pamti se u `localStorage`)
- 🔎 Filtriranje projekata po tehnologiji (HTML/CSS, JavaScript)
- 📱 Responzivni dizajn (CSS Grid `auto-fill`, mobilni izbornik)
- ♿ Pristupačnost: semantički HTML, `aria-*` atributi, vidljiv fokus, `prefers-reduced-motion`
- ✅ Validacija forme JavaScriptom (`checkValidity()`)

## Tehnologije
- HTML5
- CSS3 (Flexbox, Grid, custom properties, media queries)
- JavaScript (DOM, eventi)
- Git i GitHub Pages

## Pokretanje lokalno
```bash
git clone https://github.com/<username>/portfolio.git
cd portfolio
# otvori index.html u pregledniku
```

## Objava
Stranica je objavljena preko **GitHub Pages** (Settings → Pages → Branch: `main` / root).
